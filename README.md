PoizonTouch — это коммерческий агрегатор товаров из Китая с возможностью отслеживания заказов и полноценным интернет-магазином, если товар уже находится на складе в РФ. Проект изначально разрабатывался под конкретного заказчика, но после закрытия бизнеса остался как часть портфолио.

Проект размещён на виртуальной машине по адресу:  
🔗 [toschiy.ru](http://toschiy.ru)

## 🔧 Технологии

- **Backend**: Laravel 11 (PHP 8.3)
- **Frontend**: Vue 3, Vue Router
- **Docker**: отдельные Dockerfile для front и back, общий `docker-compose.yml`
- **БД**: MySQL, PhpMyAdmin

## ⚙️ Основной функционал

- CRUD для товаров, заказов, тегов, цветов, категорий, доставки
- Регистрация и авторизация пользователей
- Фильтрация товаров по тегам, категориям, цветам, цене
- Фильтрация заказов в админке по номеру, заказчику и статусу
- REST API на Laravel Breeze
- Роли пользователей и ограничение доступа через middleware
- Пагинация, фильтрация и сериализация на API

## 🔌 Интеграции

- Почта России (через официальный API)
- ГдеПосылка (для fallback-логики)
- ЮKassa (приём оплаты)
- Telegram-уведомления
- DaData (поиск адресов)
- ExchangeRate API (курс рубль/юань)

## 📦 Архитектура

- Слой сервисов: контроллер → DTO → сервис → ресурс
- Использование событий и слушателей для нотификаций
- Минимизация логики в контроллерах
- Чистое разделение по ролям и сущностям

## 💡 Особенности реализации

- Креативная реализация интеграции с API "ГдеПосылка": если сервис определяет, что отправитель — Почта России, выполняется отдельный запрос в их API, и данные форматируются в унифицированный ответ
- Переписанный под себя коммерческий шаблон с Themeforest
